# Anti-AI-Slop Reference

Use this for every visual artifact.

## Common Slop Signals

- Generic purple-blue gradient backgrounds with no concept.
- Floating glass cards without an information reason.
- Random sparkles, blobs, or neon rings.
- Fake logos, fake metrics, or fake quotes presented as real.
- Repeated identical cards with swapped labels.
- Decorative icons that do not map to content.
- Overstuffed dashboards with impossible data density.
- Mobile screens that look like squeezed desktop pages.
- Motion everywhere, attention nowhere.

## Better Defaults

- Start with the user's task, not the decoration.
- Use one strong layout idea rather than many weak effects.
- Make data, copy, and imagery plausible.
- Choose typography and spacing before texture and glow.
- Use repetition for system coherence, not sameness.
- Make the primary action visually inevitable.

## Craft Checklist

- Are margins intentional?
- Is type hierarchy obvious from a distance?
- Does the artifact have a focal point?
- Are colors doing functional work?
- Are images or icons necessary?
- Does motion support comprehension?
- Would a user understand what to do next?
- Does the piece feel specific to the brief?
