# Router Reference

Use this file when the artifact type is ambiguous.

## Classify The Request

Prototype if the user asks for:

- app mockup
- web app flow
- clickable demo
- iOS or mobile screens
- product experience exploration

Deck if the user asks for:

- slides
- pitch deck
- presentation
- 16:9 narrative artifact
- PDF/PPTX export from visual pages

Motion/video if the user asks for:

- animation
- explainer video
- launch video
- MP4/GIF export
- timed motion sequence

Critique if the user asks for:

- review
- audit
- redline
- visual feedback
- improve this design

Visual direction if the user asks for:

- make it premium
- make it futuristic
- give me directions
- explore design variants

## Choose Mode

Use Execute Mode when the brief is enough to produce a plausible first draft.

Use Interview Mode when missing user intent would force arbitrary choices across audience, brand, format, or artifact type.

Use Checkpoint Mode when the artifact is large, branded, or expensive to revise after scaling.

## If Multiple Artifact Types Apply

Prioritize by:

1. Requested export format.
2. Primary artifact name.
3. User's stated goal.
4. Existing project files.

Example: "Create a product launch deck with animated intro and MP4 preview" should load deck and motion references, but the deck is the primary artifact.
