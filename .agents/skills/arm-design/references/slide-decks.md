# Slide Deck Reference

Use this for presentation decks, pitch decks, strategy decks, and HTML slide systems.

## Default Format

Use HTML-first 16:9 slides. Default canvas is 1920x1080 unless the user requests another size.

## Deck Workflow

1. Clarify or infer audience, goal, length, and delivery format.
2. Create a narrative outline.
3. Produce a representative style proof for decks of five or more pages.
4. Build the full HTML deck.
5. Verify readability and visual consistency.
6. Export PDF/PPTX only if requested.

## Slide System Requirements

- Every slide should have a clear job.
- Use purposeful hierarchy: headline, proof, visual, takeaway.
- Avoid slide clones with only text swapped.
- Maintain consistent margins, baseline rhythm, typography, and visual language.
- Prefer bespoke diagrams over generic icon rows.
- Use real data and source notes when factual claims matter.

## Suggested Files

```text
deck/
  index.html
  deck-outline.md
  speaker-notes.md
  exports/
    deck.pdf
    deck.pptx
  verification/
    cover.png
    representative-slide.png
```

## Done When

- HTML deck opens locally.
- Slides fit the target viewport.
- Text is readable at presentation size.
- Requested exports are produced or limitations documented.
- The deck has a coherent narrative arc.
