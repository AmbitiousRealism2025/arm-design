# Design Direction Consultant

Use this when the user asks for visual direction, variants, or a taste-level improvement before production.

## Goal

Turn vague taste words into concrete visual systems.

## Process

1. Identify audience, artifact, emotional target, and constraints from the prompt.
2. If essential information is missing, ask one compact batch of questions or proceed with labeled assumptions.
3. Offer two to four distinct directions.
4. For each direction, define layout, type, color, surface, imagery, motion, and interaction rules.
5. Recommend one direction and explain why.

## Direction Template

```markdown
## Direction Name

Intent:
Best for:
Avoid if:

Visual rules:
- Layout:
- Type:
- Color:
- Surface/material:
- Imagery:
- Motion:
- Interaction:

First screen or slide idea:
```

## Useful Axes

- Quiet luxury vs expressive spectacle.
- Editorial density vs product clarity.
- Tactile realism vs abstract system graphics.
- Soft human warmth vs precise machine intelligence.
- Founder story vs product proof.
- Command center vs calm workspace.

## Anti-Patterns

Avoid generic purple-blue gradients, floating glass cards, meaningless glowing orbs, and filler icon grids unless the brief specifically calls for them and they serve the concept.
