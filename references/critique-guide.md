# Critique Guide

Use this when the user asks for review, critique, scoring, or "does this look good?"

Critique the design, not the designer. Be direct, specific, and actionable.

## Scoring Dimensions

Score each from 0 to 10.

### 1. Philosophy Alignment

Does the design commit to a coherent point of view?

High score:

- clear style logic
- artifact type matches the visual language
- references are used intentionally

Low score:

- mixed aesthetics
- generic AI look
- no relation between content and style

### 2. Visual Hierarchy

Can the viewer immediately tell what matters?

High score:

- clear primary/secondary/tertiary hierarchy
- readable scale
- controlled contrast
- strong focal path

Low score:

- everything has equal weight
- tiny important text
- no focal point

### 3. Craft Quality

Are details resolved?

High score:

- spacing is consistent
- alignment is clean
- type fits containers
- assets are high quality
- motion is timed well

Low score:

- overflow
- inconsistent radius/shadow
- broken image crops
- sloppy spacing

### 4. Functionality

Does it work for its intended use?

High score:

- task flow is clear
- interactions work
- export format fits use
- responsive behavior is checked

Low score:

- looks good but cannot be used
- clickable elements are dead
- deck text is unreadable
- export breaks layout

### 5. Originality

Does it avoid the expected generic solution?

High score:

- memorable concept
- specific detail
- fresh but appropriate

Low score:

- generic SaaS gradient
- stock layout
- decorative novelty without purpose

## Scenario Emphasis

| Scenario | Weight More Heavily |
|---|---|
| app prototype | functionality, hierarchy |
| slide deck | hierarchy, readability, rhythm |
| animation | narrative, timing, final frame |
| infographic | accuracy, hierarchy, labels |
| brand/launch visual | originality, asset use, craft |
| report/PDF | readability, structure, consistency |

## Common Problems

1. AI-tech cliche: purple gradients, glowing orbs, vague intelligence imagery.
2. Weak type scale: headings and body too close.
3. Too many colors.
4. Inconsistent spacing.
5. Not enough whitespace.
6. Too many fonts.
7. Alignment drift.
8. Decoration louder than content.
9. Cyber-neon used without narrative reason.
10. Density does not match the medium.

## Review Rules

- Reference concrete locations or screens.
- Explain why each issue matters.
- Suggest fixes, not just judgments.
- Separate subjective taste from functional problems.
- If there are no major issues, say that clearly and mention residual risks.
