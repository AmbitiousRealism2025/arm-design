# Codex Optimization Notes

## Why Compact Beats Colossal

GPT-5.5 can process large context, but a skill should still minimize what is loaded by default. A compact router improves activation, reduces distraction, and makes output more consistent.

## Preserve

- HTML-first artifact generation.
- Verified facts before branded design.
- Real product and brand assets when possible.
- Strong craft expectations.
- Anti-generic AI visual rules.
- Verification through screenshots, console checks, and export checks.
- Support for prototypes, decks, animation/video, variants, and critique.

## Remove Or Rewrite

- Platform-specific tool names that Codex may not have.
- Repeated instructions to ask for confirmation before useful work can begin.
- Private reasoning or chain-of-thought requests.
- Long process sections in the main skill file.
- Any wording that makes the skill trigger for ordinary frontend/backend tasks.

## Practical Trigger Heuristics

- When the user asks for "make/design/create a prototype", trigger.
- When the user asks for "fix this code bug", do not trigger unless they ask for visual redesign.
- When the user asks for "make this more premium", trigger only if a visual artifact or screenshot is involved.
- When the user asks for a deck or animation, trigger.
- When the user asks for current brand/product work, verify facts first.
